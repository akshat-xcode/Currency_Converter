# Currency Converter 💱

A clean and simple cross-platform Currency Converter built with Flutter.

## 🚀 Live Demo
Try the app directly in your browser:
👉 **[Live Web App](https://akshat-xcode.github.io/Currency_Converter/)**

---

## ✨ Features
- Multi-currency conversion (USD, INR, EUR, GBP, JPY, CAD, AUD, AED, etc.)
- Quick Currency Swap button
- Responsive on mobile, tablet, and web
- Clean and simple UI

---

## 🛠️ Getting Started

### Prerequisites
- [Flutter SDK](https://flutter.dev/docs/get-started/install)

### Run Locally
```bash
git clone https://github.com/akshat-xcode/Currency_Converter.git
cd Currency_Converter
flutter pub get
flutter run
```

### Build for Web
```bash
flutter build web --base-href "/Currency_Converter/" --release
```
